# MindPal – CRAI Hackathon 2025 Submission

## Project Overview
MindPal is a digital support platform that centralizes access to critical campus services like medical help, security response, and mental wellness support. Built for Federal University Dutse students, it offers a simple, responsive, and accessible interface that helps students connect with the right help — fast.

## Key Features
- Emergency call button (Security, Medical, SUG President, Fire Service)
- Guided Help Request (routes messages to relevant departments)
- Department-specific dashboards for tracking cases
- Mobile-friendly design (responsive on all devices)
- Student-friendly interface for fast access and communication

## 🔧 Tech Stack
- *Frontend:* HTML, CSS, JavaScript  
- *Backend:* PHP, MySQL  
- *Version Control:* Git & GitHub  
- *Database Management:* phpMyAdmin  

## How to Run the Project
1. Clone the repository
2. Run it on a local server (e.g., XAMPP or WAMP).
3. Import the database from the /database folder into phpMyAdmin.
4. Navigate to localhost/MindPal/index.php in your browser.
